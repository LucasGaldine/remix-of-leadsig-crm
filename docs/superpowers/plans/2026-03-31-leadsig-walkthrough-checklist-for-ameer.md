# LeadSig Walkthrough Coverage Checklist for Filmed Demo with Ameer

Goal: record one clean walkthrough that shows the product feels real, complete, and useful to a landscaper without wandering into unfinished or confusing areas.

## Demo flow

1. Start on dashboard
2. Show leads and qualification flow
3. Open a lead and convert it into an active job flow
4. Build and send an estimate
5. Show client approval flow
6. Show approved estimate on the job/payment side
7. Show invoice creation and payment recording
8. End on the customer/job record with clear next actions

## Coverage checklist

### 1) Dashboard
- Show the main dashboard loads cleanly
- Briefly point out priority cards or sections
- Avoid lingering here unless the numbers look good and realistic

### 2) Leads
- Open a realistic lead
- Show contact info, service details, and address
- Show lead status / qualification state if relevant
- If the pending approval flow looks polished, mention it briefly
- Avoid any obvious test leads or junk data

### 3) Lead to job workflow
- Show how a lead becomes a real scheduled/active piece of work
- If estimate visits are part of the intended story, include that path
- Keep the explanation simple: inquiry comes in, estimate gets built, work gets approved, job moves forward

### 4) Estimate creation
- Show line items being added clearly
- Show pricing, quantity, unit, and total updating correctly
- Show profit margin / surcharge / tax only if they help the story
- If estimate creation is now better on full page than modal, use the cleaner flow
- Avoid messy edits or anything that looks buggy during recording

### 5) Estimate detail
- Show the estimate detail screen in its best-looking state
- Point out line items, notes, total, and job/customer context
- If useful, show that line items can be reordered
- Do not demonstrate reorder-only change orders as a special case unless you specifically want a power-user moment

### 6) Client approval experience
- Show how the estimate is sent or shared with the customer
- Show the approval page or explain the customer link flow
- If there are pending changes / change orders, only show this if the flow is polished and intentional
- Prefer the clean happy path over edge cases

### 7) Job record after approval
- Show the job detail page after an estimate is accepted
- Show that the estimate meaningfully feeds the rest of the workflow
- Highlight anything that helps a landscaper understand what to do next

### 8) Invoice flow
- Create or open an invoice
- Show invoice totals clearly
- Show sending / marking as sent if that flow is clean
- Show payment recording if it works smoothly in this environment
- If tap to pay is not ready for a polished demo, skip it

### 9) Customer confidence details
- Show clean status labels
- Show good formatting on money values
- Show any helpful notes, attachments, or portal views that make the product feel trustworthy

## Things to avoid in the recording
- Empty states that look unfinished
- Test data with fake names unless it looks believable
- Debug-looking copy or placeholder text
- Flows that require explaining a bug workaround
- Any path that depends on saying "this part will be better later"

## Suggested talk track
- Lead comes in
- We qualify it and turn it into real work
- We build a professional estimate quickly
- The customer can review and approve it
- Once approved, the estimate flows into the job and payment process
- The crew and office both stay aligned from one system

## Pre-recording sanity check
- Use believable data
- Close stray tabs/modals
- Make sure the best-looking records are easy to reach
- Confirm the estimate and invoice examples have clean totals
- Confirm there are no obvious broken states in the chosen path

## Nice-to-have if time allows
- Show mobile responsiveness on one polished screen
- Show client portal / approval link view
- Show one small delight moment like a clean status transition or polished estimate layout
