# Getting Started: Messaging

## Overview

Messaging in LeadSig combines manual outreach with automation so teams can keep clients informed at every stage of the workflow.

## What This Area Is For

Use messaging to:

- Send direct email/SMS communication to leads and customers.
- Track message/call history for clean handoffs.
- Configure auto-responses and job/lead automation messaging.
- Standardize customer communication quality across the team.

## Core Workflow

1. Start from a lead, customer, or job record.
2. Send outbound messages (email/SMS) and log outcomes.
3. Confirm communication appears in activity/history views.
4. Configure templates and triggers in settings.
5. Test automation paths before broad rollout.
6. Review delivery and response patterns weekly.

## Key Actions and Navigation

- `Unified Activity and Search`: `/inbox`
- `Lead Messaging Context`: `/leads/:id`
- `Job Messaging Context`: `/jobs/:id`
- `Auto Responses Settings`: `/settings/auto-responses`
- `Lead Automation Settings`: `/settings/lead-automations`
- `Notification Preferences`: `/settings/notifications`
- `SMS Consent Page`: `/sms-consent`

## Role and Permission Notes

- Messaging setup is typically controlled by `owner` and `admin`.
- `sales` uses direct communication heavily for pipeline movement.
- Crew roles focus on operational updates rather than automation authoring.

## Common Mistakes and Best Practices

- Mistake: Turning on automations without template review.
- Best practice: Test templates with internal recipients first.
- Mistake: Sending messages without clear next steps.
- Best practice: End each message with one explicit action or expectation.
- Mistake: Ignoring consent and channel preferences.
- Best practice: Confirm SMS/email permissions and honor opt-out requirements.
